# Мама и малыш

Сайт детского и женского массажа в Душанбе: **https://mama-i-malish-tj.pages.dev/**.

React · TypeScript · Vite · MUI · Cloudflare Pages. Основное содержимое заранее генерируется в HTML для поисковиков и первого отображения. Русский при каждом новом открытии страницы; тоҷикӣ и English доступны через переключатель.

## Структура сайта

1. Главный экран и два направления: женский и детский массаж, по 7 видов.
2. Услуги и стоимость: подтверждённые тарифы и выбор конкретной процедуры для записи. Новым видам без подтверждённой цены тариф не назначается.
3. Специалист и условия приёма детей: с 3 месяцев, с разрешения врача, в присутствии родителя.
4. Ответы на частые вопросы.
5. Запись и консультация: форма и контакты WhatsApp/Instagram с иконками.
6. Адрес, автоматически загружаемая карта и маршрут.

Мобильная версия имеет нижнюю навигацию и поддерживает безопасные отступы экрана. Объёмные переходы следуют обычной прокрутке; `prefers-reduced-motion` отключает анимации. В браузерах без scroll timelines содержимое остаётся доступным без эффекта.

## Разработка

Node.js **24**:

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
npm run preview
npm audit --audit-level=moderate
```

Backend и ключи не нужны. Необязательная `VITE_PRODUCTION_ORIGIN` меняет SEO origin; по умолчанию используется адрес Cloudflare Pages. Приложение не хранит заявки и не использует аккаунты, Google OAuth или базу данных.

## Запись

WhatsApp подготавливает сообщение для **+992 00 733 6264**. Instagram копирует текст и открывает Direct **@mama_i_malish_tj**; при запрете копирования доступен ручной вариант. Сообщение отправляет сам посетитель. Выбранные вид массажа и получатель сохраняются в черновике; детские процедуры требуют возраста ребёнка, женские недоступны для детской записи.

## Проверки в браузере

CI устанавливает Python Playwright, Chromium и `axe-core@4.10.3`. После сборки и запуска preview:

```sh
python tests/browser/static-booking-smoke.py http://127.0.0.1:4173
python tests/browser/static-experience.py http://127.0.0.1:4173
python tests/browser/static-accessibility.py http://127.0.0.1:4173
```

Сценарии охватывают RU/TJ/EN, ширины 320–1440 px, форму, меню, карту, маршруты и доступность. Внешние запросы перехватываются: реальные сообщения не отправляются. Скриншоты сохраняются в `/tmp/mama-static-screenshots`.
