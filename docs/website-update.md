# Задание и порядок секций

Обновить сайт «Мама и малыш», сохранив название, логотип, фотографии и фирменную палитру. Сделать мобильную навигацию похожей на приложение, добавить спокойный объёмный скролл без перехвата прокрутки и с поддержкой reduced motion. Русский — язык каждого нового открытия страницы; переключение языка работает в текущем посещении.

1. Первый экран: основное предложение, запись и переход к ценам; ниже два понятных списка женского и детского массажа.
2. Услуги и стоимость: существующие подтверждённые цены и названия всех видов массажа. Для новых видов без подтверждённого тарифа — уточнение при записи.
3. Специалист и условия приёма: сведения об обучении и отдельный блок для родителей. Условия «с 3 месяцев», «в присутствии родителя», «с разрешения врача» расположены здесь.
4. Частые вопросы.
5. Запись и консультация: контакты с иконками WhatsApp/Instagram, форма с выбранным видом массажа, честный черновик сообщения.
6. Локация: автоматически загружаемая карта, адрес и маршрут.

В desktop-хедере убрать кнопку записи. На телефоне оставить компактный хедер и нижнюю навигацию. Удалить неиспользуемые файлы прежнего Supabase/Auth/admin, старого сервера и прежние Vercel rewrites. После подтверждения пользователем удаления внешнего Vercel-проекта удалён и его конфиг. Не удалять облачные записи без определения базы и состава данных.

Проверки: lint, unit tests, typecheck/build, audit, браузерные сценарии RU/TJ/EN, размеры 320–1440 px, клавиатура, форма, карта, reduced motion и axe.

GitHub: целевое название `mama-i-malish-tj`, About — https://mama-i-malish-tj.pages.dev/. Все текущие изменения одним коммитом. Пользователь подтвердил замену старой истории одним новым коммитом и удаление неиспользуемых веток; перед этим создан проверенный Git bundle. Внешние изменения требуют действующего доступа к соответствующим аккаунтам.

Незавершённые внешние пункты блокируют права: GitHub возвращает `403 Resource not accessible by integration` для изменения настроек репозитория и deployments. Обнаружены 69 старых Vercel deployments. Их следует вводить только в настройках облачной среды; для работы сайта они не нужны.
